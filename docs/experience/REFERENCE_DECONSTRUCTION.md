# Deconstrução de referências criativas

Leituras verificadas: artigo Substack de Felipe, `ofelipemart.gevia.co`, `samuelrizzon.dev`, making-of de Samuel e README de `latent-spaces/brag`. Também capturei screenshots temporários para análise visual; eles não foram copiados para o repositório.

## A. Assinaturas que não devem ser copiadas

- Escultura grega/mármore, ajudante de bronze, cinzel, “golpe a golpe” e personagens de Felipe.
- Blocos/pixel-art, agentes laranja, character sheet e “Every pixel is laid by an agent” de Samuel.
- Git City, contribution graph como construção literal, easter eggs e estrutura visual específica dos autores.
- Copy, exemplos e combinações tipográficas/paletas exatas.

## B. Princípios adaptáveis

- Uma metáfora central derivada do verbo do produto.
- Referências primeiro; três alternativas; reagir rápido com motivo; registrar rejeitados.
- Uma metáfora por tela, mas dentro de um mesmo universo.
- Dados vivos e honestos como conteúdo.
- “Show the thing”: usar produto real e componentes reais, com simulação rotulada.
- Gates objetivos: contraste, duração, cobertura, determinismo e revisão humana.
- Testar como estranho em telefone real, não apenas no browser do agente.

## C. Técnicas inadequadas ao NomadFlow funcional

- Pixel art ou game 3D como interface principal.
- Scrolljacking, easter eggs e gamificação dentro de decisões financeiras/logísticas.
- Tipografia display/pixel para dados operacionais.
- Animações longas que atrasam acesso à informação.
- Estética de dashboard SaaS sem relação com jornada.

## D. Oportunidades para o NomadFlow

- Metáfora própria: **a linha da jornada que se redesenha quando o mundo muda**.
- Motion principal: reorganização de datas, rotas e custos após uma alteração.
- Rótulos de confiança (simulado/estimado/verificação pendente) como assinatura visual.
- Explorar como atlas; viagens como expedições; comparação como caminhos alternativos.
- Making-of público do processo como ativo do hackathon.
